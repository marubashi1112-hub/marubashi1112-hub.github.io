# ごはんマップ v8（PWA）

行った飲食店を地図に記録するアプリ。ホーム画面に追加して使う。

## 中身
- index.html … アプリ本体
- manifest.webmanifest … ホーム画面に追加したときの名前・色・アイコン
- sw.js … オフラインで開くための仕組み（地図の画像も見た分だけ保存する）
- icons/ … アイコン（192・512・iPhone 用 180・Android の丸抜き用 512）

## GitHub Pages に置く手順
1. GitHub で新しいリポジトリを作る（例：gohan-map）。公開設定は Public
2. 「Add file」→「Upload files」で、このフォルダの中身を全部アップロードする（icons フォルダごと）
3. 「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして Save
4. 1〜2分待つと `https://<ユーザー名>.github.io/gohan-map/` で開ける

## スマホに入れる
- iPhone：Safari で上のURLを開く → 共有ボタン →「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「アプリをインストール」（または「ホーム画面に追加」）
- 最初に開いたとき、現在地の許可を聞かれたら「許可」

## 使い始めるとき
- 最初は見本の店が8軒入っている。「ふりかえり」（下のメニュー）の下にある「サンプルを消す」で消せる（2回押す）

## データについて
- 記録はそのスマホのブラウザの中にだけある。サーバーには送らない
- 機種変更の前に「ふりかえり」→「書き出す」で JSON を保存し、新しいスマホで「読み込む」

## 更新するとき
- index.html などを差し替えたら、sw.js の `VERSION` を1つ上げる（例：'v8' → 'v9'）。上げないと古い画面が残ることがある

## 地図
- 地図は OpenFreeMap（liberty スタイル・OpenStreetMap のデータ）。地名は日本語で表示。右上の重なりボタンで国土地理院の標準地図に切り替え。近づくとピンの下に店名が出る。地図の右下に出典を出している

## 画面
- 日記（ホーム）：食べに行った日のマスに料理の写真が入る。日付を押すとその日の記録、月は左右の矢印で切り替え
- マップ：ピンが料理の写真マス。ハートは「また行きたい」、点線は「行きたい」
- お店：一覧と検索
- きろく：ふりかえり・サンプル削除・データの書き出しと読み込み
- 真ん中の＋：記録する（いちばん上で料理の写真を追加）
- 写真がない記録は、ジャンルのくすみ色のマスに漢字1文字で表示する
